# E5 真实闭环运行单

E5 必须由小林本人执行“阶段决定 D”。脚本和 DSH 都不冒充小林。

## 0. 启动第一发生场

```bash
cd /mnt/c/Users/lnp/Documents/Playground/cognos
PYTHONPATH=phase0:web /home/lnp/projects/111/.venv/bin/python web/run.py
```

## 1. 小林 -> Gemini A，得到 A

先通过 `/api/auth/login` 登录 Cognos 并在同一 HTTP client 中保留 HttpOnly cookie。
以下写 API 均要求会话；浏览器登录也适用。账号身份是普通应用对象，不替代阶段决定者。
E4 CLI 结果回流需附加 `--username <Cognos账号>`，密码由终端隐式读取。

`POST /api/messages`

```json
{"content": "<小林给 Gemini 的真实输入>", "target": "gemini"}
```

记下返回的 `reply.id` = `A`。

## 2. 小林让 Gemini-B 面对 A，得到 B

`POST /api/messages`

```json
{
  "content": "这是 Gemini 刚才的判断。请面对它继续，不要替它圆场。",
  "target": "gemini-b",
  "quoted_occurrence_id": "A"
}
```

记下返回的 `reply.id` = `B`。

## 3. 小林阶段决定 D（人类步骤，不自动生成）

小林阅读 A、B 后，写下本次要交给 DSH 的真实指令 `D`。

## 4. A + B + D 生成 Handoff H

`POST /api/handoff/create`

```json
{
  "instruction": "D",
  "target_agent": "DSH",
  "working_directory": "/mnt/c/Users/lnp/Documents/Playground/cognos",
  "occurrence_refs": ["A", "B"],
  "source_refs": []
}
```

返回 `envelope_path`。

## 5. DSH headless 执行（只创建，不 resume）

```bash
PYTHONPATH=phase0:web /home/lnp/projects/111/.venv/bin/python -m handoff.dsh_runner \
  <envelope_path> \
  --dsh-home /tmp/cognos-dsh-home \
  --json
```

返回 `session_log_path`。如果 `/tmp/cognos-dsh-home` 不存在，先复制一份可写的 DSH_HOME：

```bash
cp -a ~/.dsh /tmp/cognos-dsh-home
chmod -R u+w /tmp/cognos-dsh-home/profiles /tmp/cognos-dsh-home/storages
```

不要写 `~/.dsh/profiles`；workspace-write 沙箱会正常拒绝。

## 6. E3 导出可观察 Result R

```bash
PYTHONPATH=phase0:web /home/lnp/projects/111/.venv/bin/python -m handoff.exporter \
  --session-log <session_log_path> \
  --working-directory /mnt/c/Users/lnp/Documents/Playground/cognos \
  --handoff-id <handoff_id> \
  --related-occurrence-id A \
  --related-occurrence-id B \
  --vault-payload-out /tmp/cognos-result-<handoff_id>.json
```

## 7. E4 把 R 回第一发生场

```bash
PYTHONPATH=phase0:web /home/lnp/projects/111/.venv/bin/python -m handoff.result_poster \
  /tmp/cognos-result-<handoff_id>.json \
  --server-url http://127.0.0.1:8765
```

## 8. 重启 FastAPI，原 Gemini / Gemini-B continuity 面对 R

```bash
# 重启 web/run.py 后
POST /api/messages
{
  "content": "这是 DSH 刚回传的 Result R。请在你自己原有连续性里面对它。",
  "target": "gemini",
  "quoted_occurrence_id": "R"
}

POST /api/messages
{
  "content": "这是 DSH 刚回传的 Result R。Gemini 也已经面对它。请在你自己原有连续性里继续。",
  "target": "gemini-b",
  "quoted_occurrence_id": "R"
}
```

## 边界

- `R` 只保存 `session_ref` + 机械提取结果，不复制完整 DSH tool log。
- 不把测试通过与“DSH 声称通过”混为一谈。
- 任何 `.env`、API key、authorization 不得进入 H / R / Vault。
