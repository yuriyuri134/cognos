# Cognos v3 当前完成边界

2026-09-21。对照用户批准的 v3 与后续“帮助 AI 思考”的要求。此表用于防止以已有功能反向缩小项目目标；测试通过不等于整体完成。

| 要求 | 当前证据及状态 | 后续必须完成或核实 |
|---|---|---|
| 保护原始发生、旧数据、普通聊天连续性 | 各批增量变更；活动请求与普通会话隔离；原始记录追加；旧协议回归通过 | 完整迁移/恢复演练及施工前快照覆盖范围仍需审计，不能把局部测试当作全量备份证明 |
| Organization 是实际环境，Activity 可从环境开始并返回 | 项目来源导入、消息/工作项/决定发布已有 API；原有使用路径保留 | 真实组织使用全程与文件返回的覆盖仍需核实 |
| 开放 Envelope，不强迫 Formation/Move/收敛 | 自动回归和真实创作/学习试用中可无 Formation 继续 | 普通聊天与活动的整体体验还需持续内容检查 |
| 输入组装清晰，历史不默认淹没当前 | 快照、请求边界标记、独立活动调用；采用组合不再自动注入依赖全文 | 活动历史的选择仍较粗；Codex 运行时额外上下文未完整捕获；不能声称已知提供方内部输入 |
| 多个理解并存并可暂缓 | 后端同 ID 修订、active/dormant、历史重建及恢复有回归；主界面显示并存读法、暂缓与逐项修订；用户现在可直接暂缓、重新启用或修订单项读法，事件进入同一 Formation 历史并改变下一轮 Context | 新增直接控制尚未完成真实浏览器验收；仍不能把状态修改解释成认识进步 |
| 理解实际影响接触与活动 | 修改采用组合会改变后续输入；显式读取仍可重开材料 | 真实试用尚不足以证明 Formation 引起了更合适的取材；不能以输入字符串变更宣称认识进步 |
| 新材料能修正既有理解 | 原文分段回读、用户表达、外部结果与失败有通路；新增独立历史浏览，不依赖当前关键词即可翻看当前项目原始发生，并标示当前字面筛选是否命中后再按 occurrence 回读全文 | 系统仍不会自动知道哪条遗漏最重要；浏览路径减少筛选盲区，但未知遗漏的主动发现与检索偏向修正仍未解决 |
| 构造形成可继续使用的新材料 | 实模型计算结果被后续 read/select 直接读取，形成下一计算 | 模型转写输入仍需内容核查；不自动等于事实或用户已理解 |
| 历史改变后续活动并保留来路 | 同项目构造带入保留实际依赖与版本，可本地修订；新增跨活动经验候选浏览，只暴露有采用/实际结果痕迹的候选，显式浏览后才进入当前 Activity，仍需再次明确带入且不会自动 adopt | 新处境适用性判断、候选排序依据、跨活动长期形成机制仍需真实证据；当前只是可发现与可带入，不能等同自主学习 |
| 运行配置可替换，身份清晰 | Adapter/profile、请求与响应信息、错误留存已实现 | 近期实模型试用的实际模型未知，不能替代原计划 GPT-5.6 high 的统一验收 |
| 开放现实、学习、创作都能展开 | 三类已有不同范围证据，学习与创作有新版本实调用 | 同一当前版本的完整三类使用复核尚未完成，旧证据不能混算为当前验收 |
| 界面可实际使用 | 隔离 Chrome 检查覆盖基础活动路径及跨活动带入；历史浏览和 Formation 直接控制已有界面实现 | 当前机器缺少 Playwright，新增两项交互尚未完成浏览器自动化复核；真实长期体验仍不充分 |
| 让经验改变以后怎样思考 | 已有持久材料、可执行构造、显式跨活动带入；现在可按实际使用痕迹发现旧 Activity 候选，并把候选目录作为新材料交给当前活动继续判断 | “有使用痕迹”不等于“当前有用”；适用范围判断、可修订推荐、跨处境形成与模型层学习仍未完成；是否训练模型保持开放 |

当前已有一条可使用的活动与构造基础，不能因此宣布“会思考的 AI 已完成”。下一阶段同时推进真实内容与缺失机制：新处境中的构造适应、多理解可见性、未知遗漏的取材、跨活动经验的选择。验证服务这些问题，不建立新的统一认知分数或固定思维流程。
