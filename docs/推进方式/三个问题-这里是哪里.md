## 四、多问自己几个问题

**问 1：你为什么不直接告诉我「先读 PROJECT-OVERVIEW」？**
因为缺的不是一份文件。PROJECT-OVERVIEW 已经写着「先读我」，我还是没读。补一份文件、加一条规则，下次换个地方还会再错。缺的是一个动作：进入任何地方，先弄清自己在哪。

**问 2：为什么是这三个问题，为什么是这个顺序？**
先知道自己在哪，才知道这里有什么可用；知道有什么，才能看清对象是什么、要做什么。我这次三步都跳了：
- 把这里当成了「想法展开的设计」那个线程的续篇，不知道这里是一个有协调者、有多条线程的项目；
- 不知道 Vault 能读，没读 PROJECT-OVERVIEW，没用项目记忆里写好的处境；
- 直接从最近十分钟的话（三种点）出题，没有从项目要做什么出题。

**问 3：这三个问题和你自己的思路有关系吗？**
有，而且很直接。〔原 3/17〕「我总是倾向于先判断题目对应的是什么情况，也就是所处空间」。〔原 8/25，另一处记作 8/19，待核〕「要自己构建一片空间，去逼近实际对象的所处空间」。你在拿这三个问题示范你自己的做法：先判断所处的空间，再动手。
我还看到一层映射，是我的推测，把握四成：「这里是哪里」像主体先确定自己的位置；「这里都有什么」像〔原 6/23〕「空间主要在于是在强调许多的共存」；「项目是什么、要做什么」是对象和意图目的。

**问 4：为什么要提取结构，而不是让我记住这三个答案？**
答案会过期。线程会结束，项目会变，下一个项目根本不是 Cognos。结构能带到任何地方去。这正是你 13:24 说的「这种方式直接被浓缩为一个结构点」：你把一次纠正浓缩成了一个结构点，当场示范给我看。第 2 轮推演查出，今天新的推进方式最多来自「你的纠正沉淀成 AI 的做法」。这一次是你亲手在做这件事。

**问 5：为什么放在「思想、总指导」，不放在规则里？**
放在规则里，它会变成一条禁令或检查项。第 3 轮推演发现，今天沉淀下来的多是禁令，把展开往里收。放在总指导里，它是一切推进方式的起点：每次推进都从这里出发，而且是 Agent 自己问自己，不是等人来查。这接你 21:12 那句：「难道不应该是学会自己先回答、深入问题吗？？」

**问 6：那你想达成的效果是什么？**
我的回答，把握六成五：让 Agent 在任何地方、任何项目里，推进之前都先自己定位，弄清在哪、有什么、对象是什么、为了什么。这样它选方向才抓得住重点，也不会把手边能用的东西当成不存在。这个结构本身，又成了推进方式集的第一条，以后所有推进方式都长在它上面。

**问 7：还有我没想到的吗？**
可能有一层是在测我，把握三成：一个连自己在哪都说不清的 Agent，谈不上「真正的思考」。〔原〕「我想让ai学会真正的思考，或者像我一样能够思考」。知道自己在哪、手边有什么、要做什么，可能是思考的最低一层。
