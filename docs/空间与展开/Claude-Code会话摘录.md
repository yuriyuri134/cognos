## 同一时间本地 Claude Code 的推进（AI 的话，不是小林确认的结论）

10/24 本地会话 `5a720e3e` 给出的框架，小林在 06:30 让它先做出来看效果：

- **描述集合 vs 模型**：模型要能产出谁都没输入过的东西（一个预测、一个矛盾、一个该问的问题）。
- **生长 vs 重组**：生长是局部往里加；重组是矛盾积累到撑不住，整套重新切分。
- **发生与读法分离**：原话、事件、结果永远不改，结构只是对它们的「当前读法」；重组就是在同一批发生上换一种读法，新旧并存比较。
- **循环**：图 → 尝试 → 撞墙 → 重组（原来说「预测」，被小林追问后改成「尝试」）。现实 = 不归这张图管、却能让它出错的东西，小林的反馈只是其中最贵的一种。
- **三空间是三种读法，不是三个容器**：同一个东西可以被读成主体、对象或世界，并在三者之间移动。
- **和普通「尝试→反馈→总结」的区别**：拿 Hermes 记忆当反例（只留结论、只会加规则、矛盾被丢掉、记忆只有一团）。
- **正在做的实验**：读法引擎，把 Hermes 会话里小林的 259 条原话按时间读，矛盾触发重组；和 Hermes 现有总结式记忆做盲测对比，看谁更能预料小林后来的反应。页面在 8780 `/index.php/apps/cognos/readings`，首页入口「主体空间（试验）」。10/24 06:55 仍在跑。
