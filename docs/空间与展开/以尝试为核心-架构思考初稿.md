## 一、尝试

**不是系统里的一个零件，是其他东西的来源。**
- 「存在之所以为存在的开始，理由。我把这个命名为尝试」（6/22）
- 「存在是尝试的延伸」（5/24）
- 「系统的搭建也是尝试，尝试比你说的这些要更大」（6/9）

之前几版都错在同一处：把尝试做成了一个回路、一个按钮或者一种记录。

**形式不预设。** 透支、判断、展开、视角、定义、关联、认知、实践、学习、创作、搭系统，都是尝试（6/22、7/12、10/24、6/3、5/31、6/9）。「任何方式都可以……但是他们又在可能或者说空间、结构内进行着生长」（7/29）。
推测：系统不提供「透支」「展开」这类入口，一次尝试是什么形式，做完才看得出来。把握 70%。

**尝试离不开的几样（不是步骤）**：靠近还没达到的（6/3）；与它指着的东西绑定（6/26）；没有保证（6/26）；碰到现实，得到反馈（6/18）。
推测：这几样不排先后。回路 v0 错在把它们排成了流水线。把握 55%。

**忽略和避开**（试读，把握 45%）：
- 忽略：尝试发生了，但没被看见，或者结果没回到发起它的主体那里。
- 避开：本该尝试的地方，被结论、候选、模板或者一个标题顶替了。

| 发生过的 | 尝试怎么了 |
|---|---|
| 「怎么赚钱」从头问了 7 次 | 忽略：上一次的尝试没留下来 |
| 9/14 系统直接给结论「卖服务」 | 避开：AI 替主体做了透支 |

| 闲鱼的两个「在吗」一直没回到系统里 | 忽略：现实的反馈没回来 |
| 1368 条笔记导入了，看不出每条「在尝试什么」（10/19） | 记录在，尝试看不见 |
| Hermes 的记忆只留结论 | 尝试被压成了结论 |

## 二、三个存在：主体、意图目的、尝试

三样各自存在，哪一样都不是另一样的属性。一次尝试可以由某个主体发起，却不朝着这个主体的意图。意图本身也可以模糊、会变：「具有结果集合导向。→而问题关键在于往往对于结果集合是模糊的」（5/26）。

推测（把握 60%）：过去很多失败，是三样被混成了一样。
- 把小林随口的一个回答记成「他的尝试」：把尝试当成了意图（8/13）。
- 直接给结论「卖服务」：拿 AI 猜的意图顶替了尝试（9/14）。
- 「当前中心」：拿一个标题去代表主体（10/24 被否）。
- 7 次从头问「怎么赚钱」：意图一直在，尝试一次都没留下来。

**对象**不是第四种存在，是方便推演的指代。意图、主体、某一次尝试，都可以被当成对象。推测：系统里不需要一个固定的「对象」类型。把握 60%。

## 三、三个空间：建模和填充

原话来路：6/23「有些想法或者尝试是出于主体本身的，有些是基于对整个现实世界的，有些则是对某些特定的对象」；9/27「首先建立对象空间……主体空间，世界空间」；10/7「简化来说就是有三个空间」；10/24「不是只是描述的集合而已……全新的映射建模方式」；08:34 的说明见第〇节。

| 用处 | 小林的话 |
|---|---|
| 填充 | 当数据库，当历史 |
| 建模 | 可视化，显现，可追踪追溯，更直接了解 |
| 映射与构造 | 可以作为一种模拟；模型可以当基础单位，或者当实验对象 |

模拟既为预知，也为在可能空间里先尝试。它和「幻觉」是两个概念，不能混用（08:43）。模型和现实冲突时，是改一处还是整个重新构造，「看情况」。

推测：
- 这和「没有固定原子」（8/8、8/12 已否）不冲突。基础单位是从填充和建模里构造出来的模型，不是事先规定的，所以仍然是相对的。把握 55%。
- 尝试可以在模型上做（模拟），也可以直接去碰现实；碰回来的结果再填回模型。把握 50%。
- 例子：如果主体空间里已经填了「没有收入、至少要 4000、普通工作都比数据标注挣得多、大陆客服没有意义」，盈利循环第 4 轮那张选项表，在模型上模拟一下就会被筛掉，不必拿到小林面前。把握 50%。
- 05:40 否掉的「当前中心」，否的可能不是建模本身，而是一种只贴标签、不填充、不能拿来模拟的东西。把握 35%，没有确认。

## 四、Agent

- 「正是因为要创立、展开和尝试，所以需要 agent 来推进这些」（10/19）
- 「要自己构建一片空间，去逼近实际对象的所处空间」（8/25）
- 只在点击或 @ 时来，不要自主心跳（10/1）
- Agent 的尝试算尝试；可以和小林的方向相差很远；怎么对待它，取决于怎么对待这个主体（第〇节）

推测（把握 50%）：Agent 的工作是自己真的去尝试，在模型上做，也去碰现实，然后把碰到的东西带回来。它不替主体透支（直接给结论），也不把尝试推回给主体（给候选让人挑）。它的尝试要留下来，不硬算到小林的意图上。
**Agent 本身怎么构建，这里没有结论。**

## 五、创立空间、示范空间和四个部分

- 创立空间：「要有一个尝试，或者抛出什么，然后那个对象展开，同时又要确立那个对象是什么」（10/19）
- 项目、学习：意图目的的显现（08:07，原话）

推测（把握 40%，小林没说过）：顺着这句往下推，组织可能显现的是多个主体（依据：「调度是主体与主体的联合」，已确认），笔记显现的是被记下来的尝试（依据：6/18「尝试要有记录」；10/19「指定我的笔记……在尝试什么」）。照这样看，创立空间就是三个存在还没有分开、还没有形状的地方。

## 六、和「普通 agent 尝试→反馈→总结」有什么不同（10/24 05:41 的问题）

推测（把握 45%）：
- 普通做法里，尝试是拿到结论的手段，结论留下，尝试丢掉。在这里，留下的是尝试；判断只是「透支的尝试，不是尝试的更深一层」（8/13）。
- 普通做法里，主体、意图、尝试是一团：一个 agent 带着一个任务，做完就结束。在这里三样分开存在，所以一次没朝着意图的尝试也会被留下，并且能看出它和哪个主体、哪个意图有关，或者无关。
- 普通做法只记反馈。在这里，反馈去填充三个空间的模型，模型又能拿来模拟下一次尝试。

## 六之二、从盈利循环纸上试验学到的（10/24 08:50–13:11）

试验记录在 `盈利循环-三空间模型-纸上模拟.md`。对架构有用的几条：

1. **每条填充都要标来源**：原话、现实反馈、AI 推测，三种分开。混在一起，模型就会被 AI 自己带偏（第 5 轮把「盈利循环」读成个人收入，就是这么来的）。
2. **每条事实都要带时间**。「每天 6–8 小时」过期了没被发现，第 4 轮就建在它上面。
3. **模型里要有放「切入点」的地方**：主体从哪里碰到世界。切入点有两个属性，能不能进（门槛），进去以后通不通。小林确认「换个位置重来」多半就是在重新找切入点（09:16）。
4. **过去的尝试，以及它们停在哪里，都要留下**：工业机器人那条线停在「没途径切入」，闲鱼停在信任，跟朋友讲项目停在「说不清楚」。
5. **意图可以有好几个**，要分开看：4000 托底，组织的经济系统。项目是一场实验，「可以覆盖到我很多目标」（13:11）。
6. **Agent 自己的思路要有地方放**：它当时知道什么、为什么这样推。小林说「我非常需要理解ai的思路……抓住些能够切入的点」（09:04）。
7. **回来时站在哪里，要记下来**：接着上次往下推，还是换一个口子，「看情况」，系统不能默认其中一种。

推测（把握 50%）：这几条不是给尝试加的字段，而是三个空间和三个存在在一次真实使用里，自己暴露出来缺的东西。
