# 创立空间的第一步：「围绕此起点继续」

> 10/24 05:40 撤回：小林指出「当前中心」和反复给主体建模没有区别。这个字段说穿了就是一个能改的标题，本身没有深意。之后改为从一个具体对象或任务切入，见线程。

2026-10-24。依据：`空间与展开-从你的原话出发.md`、PROJECT-OVERVIEW、master 上现有代码。

## 现在的情况

8780 上的创立空间（`/creations`）其实就是一个 ChatGPT 式对话：表 `cognos_creations` 只存标题，`cognos_creation_messages` 存消息，Agent 每次回答一大段。里面没有「起点」，没有「当前中心」，也看不出上次停在了哪里。笔记页只有「讨论」按钮，点了会进 Activity，进不了创立空间。10/8 卡住的就是这个缺口。

## 1. 要做的功能（一个）

**从任意一条笔记点「围绕此起点继续」→ 进入一个创立空间：顶部是一句「当前中心」，下面是一次次尝试，你可以改写中心，改过的中心都留着。**

| 改动 | 文件 |
|---|---|
| 新迁移：`cognos_creations` 加 `origin_note_id`；新表 `cognos_creation_centers`（creation_id, text, created_at）；`cognos_creation_messages` 加 `center_id` | `lib/Migration/Version001700Date20261024000000.php` |

| Agent 的提示词：给它当前中心和最近几次尝试，**只做一次尝试**，顺着内容走一段，最后一行写「停在这里：……」，不列选项 | `HermesAgentService::chatCreation` |

数据就是三张表，每条消息都知道自己是在哪个中心下发生的，所以「来路」不需要另外记。

## 2. 用什么真实起点去试

用 8/19「空间逼近」那条笔记（1368 条导入里应该有），也就是「没钱、数学理想」那段。两天里进去三次，每次只顺着走一段就停下：

- 第一次：中心就是「没钱」，看 Agent 是不是又会去写赚钱方案；
- 某一次觉得中心不对了，就自己改写（比如改成「可支配时间」之类你当时真正想到的说法）；
- 第三次进来时，先不看消息，只看顶部的中心和最后一行「停在这里」。

## 3. 怎么判断成功，或者该换方向

**算成功**：第三次进来的时候，不翻聊天记录，也能接上上次停下的地方；你至少改写过一次中心，回头看分隔线时能说出当时为什么改。

**该换方向**：
- 你一次都没改写过中心 → 「中心」不是你实际的思考方式，退回去重想；
- 你想先给东西分类、打标签，或者另外开 Obsidian 记「真正的想法」 → 这个空间没有接住你；
- Agent 的「一次尝试」还是在铺方案、给选项 → 先调提示词，调了两轮还不行就换做法。

## 4. 故意不做的

不画地图、梯度或节点图；没有节点类型；没有「展开」按钮，也没有新建空间的表单；不接 Deck、Talk 或项目；Agent 不会自己跑（不做心跳、不自动建空间）；不分支，一个起点只走一条线；不补 `wip/agent-rag-memory`；不重做示范空间的四个部分；现有「理解确认」那道关卡先不动。
