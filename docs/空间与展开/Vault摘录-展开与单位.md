## 认识论-核心（AI/认识论-核心.md, v2026-08-13）
- 九步来路：学习 → 认识论 → 拆分（限定/指认/视角）→ **存在的展开与显现** → 变化 → 主体视角（"存在是主体的不断展开与扩大"）→ 尝试 → 幻觉/可能 → 空间。螺旋，不是线性。
- 命题 1：尝试先于存在；锐化（小林 6/7）：**尝试先于空间**，伸出去的动作凿出空间。
- 幻觉是生产性的：**主体现实梯度**，越近主体越实在，越远越幻觉/可能/自由；尝试 = 用实在触碰不实在，触碰后一部分变实在，空间扩大。
- 命题 3：元概念随主体扩张而生长。生长有两手（小林 6/5）：**统一（代数）**扩大主体、归进标准形式；**分明（几何）**连接、摆成关系、分解自身。两极互借。
