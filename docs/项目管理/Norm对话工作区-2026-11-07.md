# Norm 对话工作区：#50 的审查与交付

2026-11-07，Codex。任务入口：[#50](https://github.com/yuriyuri134/cognos/issues/50)。基于 `gpt/norm-chat-first-20261107` 的 `c62f9c2`；代码从 `claude/project-thread-h23yb2` 接续。先读项目全貌、思想索引、项目设计入口及接续记录，再核对模板、CSS、聊天组件、Norm 控制器、服务和种子数据。

## 代码审查后的选择

- 实际产品是 Nextcloud 应用，`web/` 是历史原型。本次不按旧原型的结构或测试基线施工。
- 项目模板把动态置于聊天之前，各部分装进固定 400px 右栏；聊天本身只有 46vh。长动态和三列布局共同挤压阅读区。
- 消息接口返回完整历史，原聊天组件每次刷新却清空 DOM 并滚到底部。问题在呈现与阅读位置，本次继续使用完整历史接口，不截断消息。
- Norm 服务已有按空间配置的 `parts`，包括演变、拆解、关系、对照和文档。切换这些视图就能让它们使用主区，无需增加数据库结构或迁移。
- 演变、分支、关系节点目前没有经过服务核验的逐项来源地址。它们继续呈现为内容，不从标题、节点 ID 猜造跳转；`links` 提供的 Initium 对话地址仍可打开。
- 11/03 设计资料有项目工作入口、来源与历史等长期目标，11/05–06 的 Norm 已换用另一套空间呈现。本次按当前代码改善这套呈现，不把旧文档里的工作面板重新搬回，也不参与 [#49](https://github.com/yuriyuri134/cognos/issues/49) 的基础单位研究。

## 实施范围

默认进入对话。动态、待决定事项、读者提示收在一条可展开摘要里；展开内容有独立滚动范围。演变、拆解、关系等按空间已有配置切换到主区，做法、读者操作及 Initium 来源集中在“做法与来源”。切换保留对话阅读位置、各工作视图滚动位置和未变化的分支展开状态。

聊天按消息 ID 复用 DOM，只更新有变化的内容；回看历史时保留可见消息的位置，新增消息提示“回到最新”，原本位于尾部时继续跟随。没有分页、裁剪或虚拟化。对话历史可用键盘聚焦和滚动；输入法确认文字时不触发 Enter 发送。关系图沿用原 SVG 和布局，用原生对话框处理键盘关闭、背景不可操作及焦点返回；窄屏内可横向滚动，打开时居中。

仅修改前端模板、JS、CSS，增加离线回归检查和本记录。没有修改数据库、Agent 派发、来源读取、读者自动启动规则或权限。共享 `chat-box.js` 的刷新行为也会用于 Norm 首页。
