# 尝试简介与阶段记录

0.34.0，2026-11-05。对应 R04、D02 和[尝试、会话与材料](../01-产品/尝试会话与材料.md)。本轮补 P1 的尝试简介和历史阶段总结，不把它们改成另一套执行任务。

## 一句话可以开始

位置页的「尝试」和「执行工作」分别显示。只写一个名字或一句话就能保存；简介、关注、停在哪和关联记录可留空，阶段记录也不要求每轮生成。简介可以持续修改，原版本、作者和时间保留。

尝试有独立稳定身份，通过多对多关系关联位置。同一尝试在项目总览和各关联位置仍是同一个对象；位置独立成项目或合并后按稳定位置 ID 继续关联。当前至少保留一个可访问位置，关联不授予来源访问权。首版没有把无项目的每条 Initium 自动建成尝试，也不迁移覆盖旧 trace。

「进行中／暂停／告一段落」只描述这项尝试的开展。项目是否派发、工作是否完成、结果是否验证、是否采用仍由各自记录决定；项目暂停时仍允许整理已有尝试和阶段记录。

## 当前简介与历次阶段分开

阶段总结每次追加产生独立 ID，修订该阶段只增加它自己的版本。服务在同一尝试锁内分配追加顺序；同秒创建也不按随机 ID 猜先后。修订较早阶段不会把它变成最后追加的阶段。页面按开展顺序显示，入口取最后追加阶段的当前修订。

总结正文自由填写，可选阶段名和覆盖说明。覆盖了哪些思考、活动、会话或具体版本由作者说明；未选具体记录时显示「未绑定具体记录」，不假装覆盖了整个会话。成功、错误或收获仍是作者的评价，不会修改实际运行、验证、采用或关联工作的完成状态。

当前网页写入按实际登录账号记作者；没有加让代理冒用用户作者的写接口。AI 可通过入口和 MCP 读取简介、阶段和历史，自动归纳/写入的授权另行实现，不能把本轮用户编辑验收称为真实 AI 总结验收。

## 引用的是哪一份

可选引用为原消息、旧 trace、运行、具体一版当前稿、具体一版工作或外部链接。消息和 trace 按原记录编号回查，旧作者与来源不重写；当前稿和工作必须显式给版本。阶段记录与简介各自保存自己的引用，关系是用途，不是采用声明。

读取时重新核访问。已有引用后来不可访问时保留原编号和版本，显示缺失；禁止新加不可访问来源。回查按钮读取那份原记录，不跳到最新或相似文本。工作原版返回对应事件快照；运行回查返回主体、目的、状态、时间与结果消息编号，不暴露提供方配置。

外部链接标为「仅链接，未取得正文」，不会自动抓取。完整材料取得、附件缺口和工作依赖仍按原规划推进。来源选择器只列可访问的近期候选，明确提示未列数量；手写覆盖说明不需要技术编号。

## 存储与接口

五个增量表分别存尝试当前版本、多位置关系、简介历史、阶段当前版本、阶段历史；自由文字和可选关系保存为有版本的内容块，没有把每种认识动作拆成必填表单。旧发生、原文、工作和运行表保持原身份。

写入沿用账号访问、预期版本、请求幂等和事务。多个项目按统一顺序锁定后锁尝试，再处理简介或阶段；并发旧版本不覆盖，页面保留本地输入，先展示新版并由用户明确比较。相同成功请求取回原身份与版本。

- `GET /projects/{projectId}/attempts?location_id=...`；`GET /projects/attempts/{attemptId}`。
- `POST /projects/locations/{locationId}/attempts`；`PUT /projects/attempts/{attemptId}`。
- `POST /projects/attempts/{attemptId}/summaries`；`PUT /projects/attempt-summaries/{summaryId}`。
- `GET /projects/locations/{locationId}/attempt-sources` 提供有界候选；`POST /projects/attempts/reference/read` 回查具体原记录。
- 代理只读 `GET /spaces/creation/{id}/attempts` 和 `/{attemptId}`；MCP 为 `list_attempts/get_attempt`，必须与当前位置关联，独立 Codex 和桥均可读取。

位置入口最多取五份尝试及各自最近追加阶段的有界摘要，报告省略和截断。完整旧版本不自动塞进每轮上下文，按需要读取；实际运行输入保存当时给出的摘要。

## 验证与边界

`check_attempts.php` 51 项实际数据库合约；`check_attempts_api.cjs` 真实 8780 HTTP、跨账号拒绝、原版本回查与独立重组后多位置身份；`check_attempt_concurrency.php/cjs` 两组独立进程验证阶段追加顺序及简介旧版本拒绝；`check_attempts_browser.cjs` 实际表单、简介与阶段冲突、回查、共享身份、390px 和安全文本展示；`check_attempt_entry.py` 实际 MCP、无关联位置拒绝与不可变运行输入。截图已查看。

这些检查没有调用模型生成总结，不证明总结质量或完整 P1/P2 已完成。备份恢复、真实暂停/断电和外部动作 fencing、多账号、Codex 自动叫起、工作依赖及完整材料取得仍未完成。
