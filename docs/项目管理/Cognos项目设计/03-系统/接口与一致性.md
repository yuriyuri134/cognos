# 操作接口与一致性契约

[总纲](../README.md) · [数据模型](数据模型.md) · [运行恢复](../02-协作/自主推进与可靠运行.md)

本页给出首版的操作语义与候选路由；它们尚未实现，最终路由需按 Nextcloud 应用约定核对。人的页面、内嵌模型及外部适配器调用同一业务服务，避免三套状态各自更新。（S06 调用链差距、Q07）

## 读取接口

| 候选接口 | 返回内容与边界 |
|---|---|
| `GET /projects?cursor=` | 可读项目名字、稳定 ID、列表分组及下一页；不夹带未授权元数据。 |
| `GET /locations/{id}?revision=` | 当前或历史位置、主导航和可读工作摘要；旧归属可追溯。 |
| `GET /sources/{id}/revisions/{rev}?selector=&cursor=` | 原文、作者、选区、完整度、附件状态和下一页。 |
| `GET /work/{id}/context?request_id=` | 当前工作、采用、挑战、相关依据与取材目录；返回 snapshot_id。 |
| `GET /objects/{id}/history?cursor=` | 修订、采用、重组及关联运行的可读历史。 |
| `GET /runs/{id}` | 状态、输入版本、实际操作回执、成果、验证及交回情况。 |

历史和搜索分页游标绑定快照或查询版本，保证翻页期间新增消息不会挤掉旧页。无权、未取得、失效和不存在各有内部状态；对调用者的提示遵循访问边界。

## 业务操作与提交契约

首版使用直接的业务接口：确立项目、建立位置、更新当前内容、关联来源、记录/撤回决定、委托、交回结果。页面、内嵌模型和外部适配器调用相同业务服务；授权范围未接通的适配器不能获得相应写操作。

每次业务请求带 request_id 和需要比较的 expected_revision（跨对象操作用 expected_revisions）。actor 来自可信登录或绑定身份；authority_ref、basis_refs 和原消息引用按操作语义记录，不由客户端自报姓名获取权限。一个自然请求可以由服务一次完成所需的关联和历史，不要求 AI 手工逐表填报。

例如更新位置当前稿：PUT /locations/{id}/content，传 request_id、expected_revision、content，以及可选的 source_message_id。保存新修订、作者/来源和当前指针为一个事务；失败不留下半次更新。当前稿的保存不暗中撤销正式采用或用户决定。

共享提交逻辑负责权限、版本、类型、幂等与事务内历史；不在 P1/P2 建通用 operations[] 解释器或 /changes/preview 仿真引擎。change_set 是变化的记录，可用领域操作名和已验证 payload 实现，不等于对外开放任意操作语言。旧批处理协议保留在 Git 历史，等多个真实业务流程证明有重复需求时再评估。

重组使用专门 preview/commit：只预览其明确影响的归属、采用、访问范围及运行；提交时再次校验，预览不锁定未来状态。一次业务操作需要的多项写入同成同败。独立提案可先保存，再处理共享版本冲突。

## 幂等、并发与外部动作

同一调用范围内 request_id 唯一，保存请求摘要及原响应。相同 ID+相同请求重试返回原结果；相同 ID+不同内容报冲突。失败校验的重试方式与成功提交区别记录，不能让客户端误以为未提交而重复执行。

`POST /runs` 创建持久运行；`POST /runs/{id}/claim` 原子领取并返回 token；心跳、操作与完成提交核 token。`POST /results` 按 result_id 接收已产生结果；落后 token 的成果可存待核，但不得借结果接口直接改共享安排。

外部执行需要 operation_id、目标和幂等策略。无法保证幂等的外部动作失联时标 unknown，由查询/核对决定下一步；结果投递重试不调用执行工具。数据库与外部系统之间的故障窗口在运行记录中可见。

## 事件与影响

候选事件包括 source.updated、claim.challenged、adoption.changed、work.result_received、location.reorganized、grant.changed。事件含 event_id、object_id、revision、actor、cause_id 和可读 payload 引用；消费者按 event_id+target 去重。

事件驱动影响检查和运行机会，不直接代表自动采用。出现循环关联时以已访问目标去重；失败可重投，超过重试策略进入可见失败项。授权撤回要影响队列领取和共享写入，不能只更新界面。

## 首版验收契约

一次变更批次不得部分成功；并发失配不丢双方方案；旧链接和固定引用可读；原文取得范围真实；运行状态未知时不会伪装完成或自动重执行。接口测试证明这些契约，语义取材和设计判断另用真实内容验收。（对应 V03/V05/V07/V08/V09）
