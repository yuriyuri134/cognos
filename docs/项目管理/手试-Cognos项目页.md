## Initium 里连着的（还没确立成项目）

每条写你自己的起点和它停在哪。

- **跨会话档案「111」**（会话 5）。你要的是：ChatGPT Plus 网页里，一个总会话能按需读到子会话的完整历史，不用你来回搬，不另花 API 或 Codex 额度。做出了本地档案（`C:\Users\lnp\Documents\ChatGPT\111\chat-archive-mvp`，能导官方导出的 `conversations.json`），但里面只有一条虚构的测试记录；Chrome 读 chatgpt.com 被安全策略拦了。停在：真实数据一次都没走通过。那次会话自己写的下一步是：拿一个真实子会话，走一遍「取得 → 完整保存 → 另一个会话读到 → 核对原文和遗漏」。**它和项目页里的「消化」是同一个需要**：项目页要吃得进会话，才谈得上接着干活。
- **转机 / 收入**（会话 4、6）。你描述过的样子：让这个整体大量检索、多次推演判断，发现一个值得做的网页或软件，有人付费，再把现实里的事带回来改 Cognos。挂单接服务被你否了：〔原〕「直觉上很低效，中间有很多模糊环节要克服，然后反馈也不一定有，回报还很小」；电子书、专栏也是 AI 提的，你没认。停在：方向没定。Cognos 里「盈利循环」那片空间也停在 10/27。
- **一个存在能怎么存在**（会话 2、7）。〔原〕「我在思考一个项目。我就从头开始想，如果我需要什么来帮助我的话……」「甚至把项目也当成一个存在的话，既是项目本身能怎么存在，又是存在与存在之间的问题」。会话 7 往语言学、逻辑、哲学里找过工具，AI 提的路线是形式语义学、模型论、概念工程，你没定。停在：〔原〕「你怎么从这么广义抽象然后就细分几个具体情况就没了呢？根本涵盖不了」，这一下到现在没人接住。
- **尝试有哪些方式**（会话 8）。〔原〕「认识论或者方法论里，尝试的方式或者方法都有哪些，或者思考」。AI 给了八个观察维度，自己也说没证明合适。和上一条是一根藤上的。
- **ABC：很短的输入能不能触发复杂、可组合的运算**（会话 1）。〔原〕「有没有可能通过一种特殊的方式，使得模型接收输入后，进行特定的运算组合……但 ABC 并不长」。走到了状态、表示、能力，停在：〔原〕「你后面说的这些都是值得深入的，所以现在就比较迷茫」。会话 1 留了一个现成的检验：**半年后重新打开 ABC，能不能找回原来的问题、当时怎么推的、碰到的限制、没验证的路。** 可以拿来试Initium。
