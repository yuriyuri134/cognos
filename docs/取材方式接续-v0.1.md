# 取材方式接续 v0.1

Codex，2026-09-11。实现总设计 v0.2 中“正在采用的组织影响实际取得什么”的一段关系。不是新的认识类型定义。

## 这次具体增加了什么

活动可以采用一份取材定义。该定义使用现有组合操作，求值得到明确的取材参数；参数可以读取活动中正在改变的内容。执行时按这些参数取得真实项目记录，把结果保存为新的保留原文材料，然后继续交回同一活动。

当前只接入 `project_history`：当前项目里的原始发言与已返回的执行结果。字面包含、完整作者名、记录类型与指定发生标识决定哪些记录被返回。它不是语义检索，不扫描整个 Vault，不读取其他项目，也不自动联网。查询未找到内容就是空结果，不能据此断言相关知识不存在。

为什么保存取材定义而不是只加一个搜索框：活动中形成的区分可以改变定义所读取的参数；这项变化实际决定下一次读取的材料，并可以跨次承接。人和模型仍负责提出与理解那个区分，程序负责按采用关系执行。

## 一次连续运行

1. 在活动里写入或修改一项当前关心的区分。
2. 一份 JSON 组合读取它，形成取材请求。
3. 采用这份取材定义。采用只检查和保存使用关系，不执行查询。
4. 点击“按当前方式取得材料”，或让模型提出 `acquire`。
5. 服务读取当前项目记录，保留这次请求、定义版本、原始记录标识、原作者与实际返回内容。
6. 新材料进入当前活动；模型的同一轮续接会收到实际结果与文档标识。它可以继续解释、修订取材方式，或改变当前展开。

取材与材料展开分别采用。一次取得的新材料不会偷偷替换旧结果，也不会自动被宣布为正确解释。后续展开使用哪些结果，仍有明确的采用关系。当前活动只有这两种已实现的使用位置，它们不被认领为世界或认识的完整分类。

## 版本与运行契约

采用的定义及其嵌套调用固定版本。普通材料读取未指定版本时，使用当前活动快照中的最新版：修改查询参数可以改变下一次实际取材；编辑取材程序本身需要重新采用。参数变得不合法时明确失败，不回退旧查询。

GET `/api/activities/{id}/acquisition` 只预览请求，不取得记录。POST `/api/activities/{id}/acquire` 使用明确的修订与请求标识执行。同一请求重试返回原执行，不重复加入材料；活动在期间改变会返回冲突。

模型通过 `adopt_source`、`release_source` 修改使用关系，通过 `acquire` 执行。新材料标为不可覆盖，原作者保存在每条返回记录中；检索服务的身份与原作者分开。最多返回 20 条，每条最多 6000 字符，节选范围与截断明确标出。

当前提供方只是按最新发生优先筛选。检索自身的结果回执与活动修改请求不进入候选，避免把一次检索产生的包装再次当作源材料。原始记录仍按来源纪律保存。

如果取材成功后活动修订发生冲突，实际取得的结果仍保留在发生记录中，但不强行写进已改变的活动。数据库与发生记录之间仍无跨文件事务；这项限制没有因新增接口消失。

## 已发生的实际使用

我在此前的真实设计试用活动中继续操作，没有重新制造脚本模型回复。当前任务的 Codex 直接提交修改和调用取材服务，发起者记为 Codex。

| 活动修订 | 实际动作与返回 | 对后续的作用 |
|---|---|---|
| 4 → 5 | 按作者“设计试用参与者”和“预期”取材，取得原始发生 `bf180669-7328-48fa-b523-761ca07bc3df`。 | 模型关于必要条件的原提议成为可直接重读的活动材料。 |
| 6 → 7 | 修改参数，按作者“Codex（设计试用）”和“不是小林的新确认”取材，取得原始发生 `f54c474f-0900-42a7-a078-b7fa6722774c`。 | 我此前反对收窄为纠错条件的内容进入活动，其地位没有变成用户确认。 |
| 7 → 8 | 创建并采用一个读取这两份真实结果的并置定义。 | 当前实际展开同时包含两种来路；旧总设计和旧续写仍可重读。 |

这段使用证明查询参数的变化产生了不同的真实取材，并且所得材料获得了当前组织作用。它没有证明模型更聪明，也没有让程序裁决两种解释。关于“哪些条件足以承载重开组织、为何形成某个方向”的语义判断仍由参与者进行。

这不是整体架构已被来源核验取代。学习与创作仍参与总设计；此处以已存在的真实设计材料接通一项关系，更广的图像、现实环境与操作通路还需要继续建设。

## 使用入口与下一处边界

本次完整工程检查为 117 项通过，浏览器检查为 16 项通过。新增检查覆盖实际查询随参数变化、取材定义版本、当前项目范围、结果类型、节选标注、回执排除与重试不重复。模型续接的工程检查使用脚本替身；上节的实际设计取材由 Codex 直接参与，两种证据不合并为认识效果评分。

进入活动中的“当前怎样取得新材料”，填写字面包含、原作者或内容范围，采用后查看实际请求，再执行取材。返回记录会直接显示原作者与正文；完整结构与来源标识可在结构化内容中查看。

同一编辑区也可以修改取材定义，并明确采用新版本。停用只解除当前使用关系，不删除已取得的材料。

更广的通路应各自说明取得契约和可改变的参数，再接入这一段活动。当前没有新增任意命令执行或自动后台查询；外部行动继续复用原 Handoff/DSH 链。这里的进展是把一项实际取材接回了当前采用、修改和接续，而非完成了开放世界的全部接触能力。
